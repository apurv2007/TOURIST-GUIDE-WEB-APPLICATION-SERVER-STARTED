## 🌟 Overview
This project is a complete **Tourist Guide Web Application & Desktop Management System** built **100% in Python**, adhering strictly to the university course syllabus (CE0525). It uses **Flask** for the web application UI/backend, **Tkinter** for the desktop admin GUI, **Pandas, NumPy, and Matplotlib** for scientific computing & statistical analytics, **Singly Linked Lists** for day-by-day tour itineraries, **Selection & Merge Sort** algorithms for sorting destinations, **Linear & Binary Search** for queries, and **Regular Expressions** for input validation.

## 🚀 How to Run the Project

### 1. Launch the Flask Web Application (Website)
Run the following command in PowerShell / Terminal:
```bash
python app.py
```
Open your browser and navigate to:
```
http://127.0.0.1:5000
```

### 2. Launch the Desktop Admin Management GUI (Tkinter)
Run the following command in PowerShell / Terminal:
```bash
python admin_gui.py
```

### 3. Run the Unit Test Suite (Verification)
Verify 100% syllabus compliance:
```bash
python test_suite.py
```
